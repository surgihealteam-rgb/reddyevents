# REDDYEVENTS Website

A premium, responsive static website for REDDYEVENTS, Hyderabad.

## Files
- `index.html` — complete website
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `assets/` — place your real event photos and logo here

## GitHub Pages
1. Create a GitHub repository, e.g. `reddyevents-website`.
2. Upload all files/folders from this package.
3. Go to Settings → Pages.
4. Choose Deploy from branch → `main` → `/ (root)`.
5. Save. Your site will publish through GitHub Pages.
